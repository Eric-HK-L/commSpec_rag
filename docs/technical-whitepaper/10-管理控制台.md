# 10 — 管理控制台

## 10.1 概述

Admin 控制台是系统的运维管理中心，基于 Next.js 14 App Router 构建，提供知识库管理、搜索测试、反馈分析、系统监控等功能。

**访问地址**: `http://localhost:3000/admin`

## 10.2 功能模块

### 仪表盘 (`/admin`)
- 系统统计 (文档数、chunks、Release 分布)
- BM25 索引状态
- Manifest 记录数
- 最近活动时间线 (摄入记录 + 用户反馈)
- 快速操作入口

### 文档管理 (`/admin/documents`)
- 文档列表浏览 (分页、搜索)
- 规范编号 + Release 过滤
- 摄入状态标签 (✅ 已摄入 2025/xx/xx)
- 单文档详情查看
- Manifest 条目删除

### 搜索测试 (`/admin/search`)
- 对比测试: 同时展示 search + ask 结果
- 搜索耗时分解: 🔍 检索 ms + 🤖 LLM ms + 🎯 精排 ms
- Reranker 开关 (请求级切换)
- React Markdown 渲染回答
- 来源追溯链接

### 反馈分析 (`/admin/feedback`)
- 用户反馈列表 (分页)
- 按状态/评分筛选
- 反馈详情查看
- 标记已处理

### 系统日志 (`/admin/logs`)
- 实时日志尾行
- 按级别过滤 (INFO/WARNING/ERROR/ALL)
- 可配置行数

### 系统健康 (`/admin/system`)
- Python 版本 + 平台信息
- 服务运行时间 (Uptime)
- 内存使用 (已用/总量/百分比)
- 磁盘使用
- Milvus 连接状态
- 嵌入缓存统计 (条目数/MB)
- 在线搜索配置状态

## 10.3 Admin API 端点

参见 [[附录B-API接口文档]] 获取完整 API 参考。

### 核心端点
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/stats` | 增强统计 (含 manifest + BM25) |
| GET | `/api/v1/admin/manifest` | 完整 manifest 清单 |
| DELETE | `/api/v1/admin/manifest/{key}` | 删除单条记录 |
| POST | `/api/v1/admin/ingest/trigger?mode=incremental` | 触发摄入 |
| GET | `/api/v1/admin/ingest/status` | 摄入运行状态 + 日志尾 |
| GET | `/api/v1/admin/logs?level=ALL&lines=100` | 系统日志 |
| GET | `/api/v1/admin/system` | 系统健康信息 |
| GET | `/api/v1/admin/config` | 非敏感配置视图 |

### 配置视图响应
```json
{
  "llm_model": "gpt-4o-mini",
  "llm_base_url": "https://api.openai.com/v1",
  "embedding_device": "cpu",
  "embedding_provider": "local",
  "chunk_size": 512,
  "dense_top_k": 100,
  "bm25_top_k": 100,
  "milvus_host": "localhost",
  "milvus_port": 19530,
  "online_search_enabled": false,
  "reranker_enabled_by_default": true
}
```

## 10.4 前端技术栈

- **框架**: Next.js 14 (App Router) + TypeScript
- **样式**: Tailwind CSS + 自定义主题变量
- **Markdown**: react-markdown + remark-gfm (表格/GitHub 风格)
- **状态**: React Hooks (useState, useEffect, useRef)
- **API 客户端**: `frontend/lib/api.ts` (TypeScript 类型安全的 HTTP 封装)

详见 [[03-关键技术选型#3.6 前端技术决策]]

## 10.5 导航结构

```
/admin
├── /documents          # 文档管理
│   └── /[id]           # 文档详情 (动态路由)
├── /search             # 搜索测试
├── /feedback           # 反馈分析
├── /logs               # 系统日志
├── /system             # 系统健康
├── /ingestion          # (旧) 摄入管理
└── /login              # 登录页
```

所有路由在 `frontend/app/admin/layout.tsx` 中通过侧边栏导航统一切换。
