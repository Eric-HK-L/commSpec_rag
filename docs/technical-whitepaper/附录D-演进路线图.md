# 附录 D — 演进路线图

## D.2 近期规划 (v0.3.x)

### v0.3.0 — 质量增强
- [ ] 术语词典翻译 (术语表中英映射，替代 LLM 翻译确定性保证)
- [ ] NN 路由器启用 (训练小分类器自动路由简单/复杂查询)
- [ ] 反馈闭环 (用户反馈自动触发检索策略调整)
- [ ] RAGAS 评测框架集成 (自动化检索质量评估)

### v0.3.1 — 扩展支持
- [ ] R19 规范支持 (当前仅 R18)
- [ ] PPT/PDF 格式支持 (扩展 Docling 管线)
- [ ] 多 Collection 管理 (按 Release 分离向量库)
- [ ] 嵌入模型热切换 (运行时切换嵌入模型)

### v0.3.2 — 运维增强
- [ ] Grafana Dashboard 完善 (预置面板 + 告警规则)
- [ ] 分布式追踪 (OpenTelemetry)
- [ ] 自动扩缩容 (水平扩展 API workers)
- [ ] 数据备份恢复 (Milvus backup + manifest 快照)

## D.3 中期规划 (v0.4.x)

### v0.4.0 — 智能化
- [ ] 意图感知路由 (查询分类: 定义/流程/对比/故障排查)
- [ ] Few-shot 示例注入 (根据查询类型注入相关示例)
- [ ] 对话上下文管理 (多轮对话历史感知)
- [ ] 主动学习 (从用户反馈中优化检索策略)

### v0.4.1 — 企业化
- [ ] SSO/OAuth 认证 (LDAP/SAML)
- [ ] 多租户隔离 (按部门/项目)
- [ ] 审计日志 (操作追溯)
- [ ] 配额管理 (API 调用限制)

## D.4 长期规划 (v1.0.0+)

- **知识图谱集成**: 基于 3GPP 规范构建实体关系图，辅助推理
- **多模态检索**: 支持架构图、流程图等图片检索
- **离线大模型**: 内置量化版 LLM (如 phi-3, 无需外网)
- **联邦检索**: 跨组织知识库联盟搜索
- **标准合规检查**: 自动验证配置是否符合 3GPP 规范要求

## D.5 技术债务

| 项目 | 优先级 | 说明 |
|------|--------|------|
| `precomputed_loader.py` 移除 | 低 | 已废弃 (2026-07-14)，保留兼容 |
| 嵌入测试 mock | 中 | 使用真实 BGE-M3 增加测试稳定性 |
| API 版本化 | 低 | 当前 v1 无破坏性变更计划 |
| TypeScript strict mode | 低 | 部分 `any` 类型待优化 |
| Docker 多阶段构建优化 | 中 | 镜像体积偏大 |

## D.6 贡献指南

1. 新功能先在 `feature/` 分支开发
2. 新增代码需同步更新测试
3. API 变更需更新本白皮书
4. 配置变更需更新 `.env.example`
5. 前端组件变更需通过 `next build` 编译
